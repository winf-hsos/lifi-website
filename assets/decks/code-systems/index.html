what a code system is

a letter is a number. the letter comes back only when someone draws it again.
Die Definition, knapp: eine vereinbarte Zuordnung von Zeichen zu Folgen von Symbolen. Und gleich eine echte Tabelle dazu, ASCII, die älteste noch täglich benutzte. Gespeichert wird nur die Zahl, genauer die Bits darunter. Einen Buchstaben als Form gibt es im Rechner nirgends; er entsteht erst wieder, wenn ein Programm die Zahl nachschlägt und die passende Form malt. Nebenbei: Die 65 ist nicht die Position im Alphabet. Der Anfang der Tabelle gehört den Steuerzeichen, deswegen fängt das große A erst bei 65 an. Und das kleine a ist eine ganz andere Zahl als das große: Für den Rechner sind es zwei Zeichen, nicht zwei Formen desselben.

the same letter, three code systems

agreed, not given by nature. that is why there are several.
Wenn ein Code eine Tabelle ist, dann kann es mehrere geben, und es gibt sie. Dasselbe A ist in ASCII eine Bitfolge, in Morse ein Punkt und ein Strich, in eurem Alphabet eine Farbfolge. Keine dieser Fassungen ist richtiger als die andere; welche gilt, ist verabredet. Dazu drei Abgrenzungen, weil sie im Alltag ständig durcheinandergehen: Ein Code verbirgt nichts (das ist Verschlüsselung), er verkleinert nichts (das ist Kompression), und er ist kein Programmtext. Er ist im Gegenteil öffentlich, gerade damit beide Seiten ihn benutzen können.

when the table is too small

one table was too small. so a bigger one was agreed.
Erst raten lassen, welche der sieben Zeichen ASCII kennt. Die 128 Plätze reichen für Englisch und für sonst nichts: kein Umlaut, kein Eurozeichen, kein Griechisch, kein Chinesisch, kein Emoji. Genau derselbe Fall wie eben beim Codebuch, nur weltweit: Die Tabelle war zu klein, also hat man eine größere vereinbart. Unicode gibt jedem Zeichen jeder Schrift eine Nummer, weit über 100.000 Stück. Und dann kommt noch ein zweiter Schritt, den man leicht mit dem ersten verwechselt: UTF-8 legt fest, wie diese Nummern als Bytes aufgeschrieben werden. Häufige Zeichen bleiben dabei ein Byte, seltene brauchen bis zu vier.

the same table, both directions

decoding is the same table, read the other way.
Das ist der eigentliche Programmierauftrag. Solange keine zwei Zeichen dasselbe Codewort haben, trägt eine Tabelle beide Richtungen; im Programm dreht ihr sie einmal um. Zwei getrennt gepflegte Tabellen sind kein Fehler, aber ein Risiko: Ändert jemand die eine und vergisst die andere, seid ihr bei der Folie von eben und bekommt sauberen Unsinn.

one pixel, three numbers

the same three numbers your sender writes: led.set_color(236, 171, 3)
Bilder sind derselbe Gedanke wie Text, nur mit anderer Vereinbarung: je Bildpunkt drei Zahlen von 0 bis 255. Viel Rot, etwas weniger Grün, fast kein Blau, zusammen dieses Gold. Multipliziert, nicht addiert, denn jede Rotstufe lässt sich mit jeder Grün- und Blaustufe kombinieren: 256 mal 256 mal 256 sind 16,7 Millionen Farben, 24 Bit je Bildpunkt. Hexadezimal ist nur die kompakte Schreibweise dafür, zwei Stellen je Byte, aus dem Input davor. Und der Punkt für euch: Genau diese drei Zahlen schreibt euer Sender. Eure LED mischt wie ein Bildschirm, euer Sensor misst in denselben drei Kanälen zurück.
