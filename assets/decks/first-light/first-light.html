the strange codes inside? you do not have to understand them.
Die Lampe brauchen wir dreimal, in drei Farben. Statt die Zeilen dreimal zu schreiben, geben wir ihnen einen Namen: Das ist eine Funktion. Die seltsamen Zeichen mit dem Backslash sind Anweisungen an das Terminal: Hintergrundfarbe an, und am Ende wieder aus. Dazwischen zwölf Leerzeichen, die dadurch farbig werden. Ihr müsst die Codes nicht lernen, das ist gerade der Sinn der Funktion: Wer sie benutzt, muss nur wissen, was sie tut. Schritt 1: def heißt definiere. r, g und b sind Parameter, Platzhalter für Werte. Schritt 2: Beim Aufruf setzt ihr die Werte ein; lamp(0, 200, 0) ist grün. Die Funktion gehört oben in die Datei, unter import time; die zwei Zeilen darunter sind nur zum Ausprobieren. Wenn statt einer Farbe seltsame Zeichen erscheinen, lauft ihr im alten Windows-Terminal: fragt euren Assistenten. Schritt 3: Und jetzt die erleichternde Nachricht: Die seltsamen Codes in der Funktion müsst ihr nicht verstehen. Ihr dürft, aber ihr müsst nicht. Warum, zeigt die nächste Folie.

why functions help

a function hides the details.
you need to know what lamp() does, not how.
print() and input() are functions too. did you miss their insides?
next week, led.set_color() hides a whole device.
curious? open it up with your assistant.
Das ist eine der wichtigsten Ideen des Programmierens, und ihr habt sie gerade benutzt. Eine Funktion versteckt Einzelheiten hinter einem Namen. Schritt 1: Um lamp zu benutzen, müsst ihr wissen, was sie tut: eine Lampe in der Farbe r, g, b zeigen. Wie sie das macht, müsst ihr nicht wissen. Schritt 2: Das habt ihr heute schon zweimal erlebt, ohne es zu merken. print und input sind auch Funktionen, und in ihnen steckt viel mehr als in lamp: Zeichen kodieren, mit dem Terminal reden, auf die Tastatur warten. Hat euch das gefehlt? Schritt 3: Nächste Woche tauscht ihr lamp gegen led.set_color, und dahinter steckt ein ganzes Gerät mit USB, Brick Daemon und Platinen. Ihr benutzt es trotzdem mit einer Zeile. So beherrscht man Komplexität: nicht indem man alles versteht, sondern indem man sie in Teile packt, deren Inneres man nicht jedes Mal kennen muss. Das begegnet uns im Semester wieder, unter Abstraktion und Schichten. Schritt 4: Wer trotzdem wissen will, was in lamp steckt: Fragt euren Assistenten. Er erklärt euch jedes Zeichen.

step 5 · decide which colour

for remaining in range(seconds, 0, -1):
if remaining <= 5:
lamp(255, 200, 0) # yellow
else:
lamp(0, 200, 0) # green
print(remaining, "s")
time.sleep(1)
lamp(255, 0, 0) # red
print("time is up!")
if the condition is true, the first block runs. otherwise, the else block.
Die letzte Zutat: eine Entscheidung. Neu sind die gelben Zeilen. In jeder Runde der Schleife fragt das Programm: Sind es noch fünf Sekunden oder weniger? Dann gelb, sonst grün. Nach der Schleife einmal rot. Schritt 1: if prüft eine Bedingung, die wahr oder falsch ist. Ist sie wahr, läuft der eingerückte Block darunter, sonst der Block unter else. Genau einer von beiden, nie beide. Was hinter dem Rautezeichen steht, ist ein Kommentar: für Menschen, Python überliest ihn. Probiert es mit 8 Sekunden.

the whole program

import time def lamp(r, g, b): on = f"\033[48;2;{r};{g};{b}m" off = "\033[0m" print(on + " " * 12 + off, end=" ") text = input("How many seconds? ") while not text.isdigit(): text = input("Digits only, please: ") seconds = int(text) print("Timer:", seconds, "seconds") for remaining in range(seconds, 0, -1): if remaining <= 5: lamp(255, 200, 0) # yellow else: lamp(0, 200, 0) # green print(remaining, "s") time.sleep(1) lamp(255, 0, 0) # red print("time is up!")
